# 📸 Photo Gallery Application

A backend-focused Photo Gallery Application built using Node.js and Express.  
This project demonstrates CRUD (Create, Read, Update, Delete) operations and helps in understanding fundamental backend development concepts.

---

## 🚀 Features

- 📤 Upload photos  
- 📄 View all photos  
- ✏️ Update photo details  
- ❌ Delete photos  
- ⚡ RESTful API implementation  

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js  
- **Database:** MongoDB *(Hands-on learning of schema design, data modeling, and CRUD operations using Mongoose)*  
- **Tools:** Postman (API testing)
